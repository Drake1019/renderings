## If geometry is still wrong

1. Download `MARKUP-north-v6.png` and/or `MARKUP-se-v6.png`
2. Circle / arrow the wrong parts on the **RIGHT** (render) side
3. Upload the marked file back to `render_assets/scenes/` and commit
4. Reply with a short note (e.g. "window too tall", "roof step missing", "wall too long")

That is the fastest way to lock remaining geometry — SketchUp thumbnails and AI still drift on fine massing.
